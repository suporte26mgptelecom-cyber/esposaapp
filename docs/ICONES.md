# Ícones usados na versão 1.3

- **Wellness:** `app/src/main/res/drawable/ic_wellness.xml`, símbolo W branco sobre quadrado vermelho que já era o ícone do aplicativo. O mesmo recurso foi reutilizado no cabeçalho, sem gerar uma nova logo.
- **YouTube:** path vetorial consultado em <https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/youtube.svg> em 24/10/2026. Convertido para VectorDrawable, usando a cor vermelha da paleta do aplicativo.
- **TikTok:** path vetorial consultado em <https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/tiktok.svg> na mesma data. Convertido para VectorDrawable monocromático branco.

Os ícones YouTube/TikTok são do projeto [Simple Icons](https://github.com/simple-icons/simple-icons), cuja licença do conjunto é [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Nomes e símbolos identificam os serviços que serão abertos. O ícone de voltar é uma seta de navegação; não é uma nova marca do Wellness.
